# Metadata Type Names

`metadata_type_name(type, container_version)` returns a registered class name
or an empty view when that version and index have not been verified.

- Container version 103 exposes indices 0–183.
- Versions 431 and 448 expose indices 0–44.
- Omitting the version exposes only indices 0–44, which are stable across the
  verified generations.

A registered class name identifies the record class; it does not mean the
reader decodes every field in that class.
